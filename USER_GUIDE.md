# Bender - User Guide

The full installation and user guide is in [docs/Bender_User_Guide.pdf](docs/Bender_User_Guide.pdf). Its source text is [docs/guide/Bender_User_Guide.md](docs/guide/Bender_User_Guide.md), so you can also read it on GitHub.

The guide covers:

- installing Bender and checking the release signature
- each of the eight tabs: System, Security, Network, Connections, Maintenance, Weather, Proxy and About
- what every Maintenance action deletes or changes (each one asks before it runs)
- what goes over the network, and the weather location Bender remembers
- turning on Tinyproxy filtering so the blocklist takes effect
- troubleshooting
